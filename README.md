# Crafting Reimagined / Better Crafting

OFFICIAL MODRINTH LINK: https://modrinth.com/mod/craftingreimagined

**Crafting Reimagined** is a client-side Minecraft Fabric mod designed to make crafting faster, and more easier / simpler, you can see it as a crafting tweaks mod.

The goal of this project is to make a JEI style crafting interface, but different than JEI it will not require for the server to have installed it, and is far more simpler to use for everyone, including extra crafting tweaks such as knowing how much materials you need for a certain item amount.

## Features (Planned)

- **Recipe Browser** — Search and explore Minecraft crafting recipes, brewing recipes and smelting recipes.
- **One-Click Crafting** — Automatically place ingredients into crafting tables, furnaces, or brewing stands.
- **Custom Crafting Amounts** — Choose exactly how many items you want to craft, using your scrollwheel or by clicking a + button
- **Craft Maximum** — Calculate and craft the maximum possible amount with your materials or how many materials you will need for it.
- **Inventory Scanning** — Automatically detect available crafting materials, and add them into the material list of what you already have.
- **Multiplayer Support** — Use normal Minecraft inventory interactions without requiring server-side installation.
- **Customizable Settings** — Adjust crafting behavior and automation delays.
- ***Have an GUI that counts how much of each item you need while playing and collecting that item*** - WIP

## Compatibility / Plans for other versions

- **Minecraft:** Java Edition 26.2 / Possibly will make 1.21.11 and 26.3 mod files too since a lot of servers still support it.
- **Mod Loader:** Fabric will be the main modloader with a ported version to neoforge comming in the future.
- **Java:** 25
- **Extra:** Will require some additional libraries listed in modrinth until I set up my own one.

This is not a server side mod. But some servers may restrict automated inventory interactions or use unsupported custom recipes, which we will try to support by scanning datapacks / resource packs but that's a W.I.P.
